Deploy the shop through Argo CD.

Argo CD reads GitHub, not your laptop. Push kubernetes/ to main first
if those files are not on origin yet.

1. Point kubectl at the cluster
   aws eks update-kubeconfig --name my-eks-cluster --region us-east-1

2. Register the app (this is the only kubectl apply you need)
   cd /mnt/c/Users/guyol/ultimate-devops-project-demo
   kubectl apply -f argocd/application.yaml

3. Argo CD creates namespace otel-demo and syncs kubernetes/ by itself.

Check:
  kubectl get application otel-demo -n argocd
  Expected: SYNCED  HEALTHY

  kubectl get pods -n otel-demo
  Expected: 22 pods (one per Deployment, replicas: 1).
            All STATUS Running when healthy.
            A few may show Init for a minute (cart waits on Valkey;
            accounting and fraud-detection wait on Kafka).

Shop URL: https://shop.simsoliver.com
Jaeger UI: https://jaeger.simsoliver.com/jaeger/ui
           (also https://shop.simsoliver.com/jaeger)
Argo CD UI:  https://argocd.simsoliver.com  (application: otel-demo)

If the repo is private, add Git credentials in Argo CD before step 2.
