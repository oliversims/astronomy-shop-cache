Cart
====

What it does
------------
The shopping basket: add, remove, and list items. It does not keep
that state in the cart process itself. It reads and writes Valkey.

It waits for Valkey to be ready before it starts. flagd can fail
cart operations (cartServiceFailure).


Related services
----------------
Uses:
  valkey   basket storage
  flagd    optional failure

Called by:
  frontend   view / change the basket in the UI
  checkout   read the basket at place-order

Also sends telemetry to otelcol (OpenTelemetry Collector).
