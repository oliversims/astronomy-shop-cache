Prereq (once):
  aws eks update-kubeconfig --name my-eks-cluster --region us-east-1

1) ExternalDNS add-on
  aws eks describe-addon --cluster-name my-eks-cluster --addon-name external-dns --query "addon.status" --output text

  Expected: ACTIVE

2) ExternalDNS pod
  kubectl get pods -n external-dns

  Expected: 1 pod, STATUS Running

3) IAM role
  aws iam get-role --role-name my-eks-cluster-external-dns-role --query "Role.RoleName" --output text

  Expected: my-eks-cluster-external-dns-role

DNS records for argocd/grafana appear later, after those Ingress objects exist (06 and 07).
