Prereq (once):
  aws eks update-kubeconfig --name my-eks-cluster --region us-east-1

1) Monitoring pods
  kubectl get pods -n monitoring

  Expected: Grafana, Prometheus, Alertmanager, exporters STATUS Running
            (some may be 2/2 or 3/3 Ready)

2) Ingress (Grafana only)
  kubectl get ingress -n monitoring

  Expected:
    NAME      CLASS   HOSTS                     ADDRESS
    grafana   alb     grafana.simsoliver.com    k8s-myeksclu-....elb.amazonaws.com

  Same ADDRESS as Argo CD (shared ALB group my-eks-cluster-public).

4) URL
  Open: https://grafana.simsoliver.com
  Login: admin
  Password (PowerShell):
    kubectl get secret kube-prometheus-stack-grafana -n monitoring -o jsonpath="{.data.admin-password}" | ForEach-Object { [Text.Encoding]::UTF8.GetString([Convert]::FromBase64String($_)) }
